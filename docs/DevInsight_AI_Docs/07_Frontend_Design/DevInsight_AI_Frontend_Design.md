# Volume 7: Frontend Design

## Frontend Technology

- Next.js
- TypeScript
- Tailwind CSS
- React Query or similar data fetching
- Markdown renderer
- Chart library for statistics

## Frontend Responsibility

The dashboard is the control panel for DevInsight AI.

It handles setup, management, history, statistics, and report requests.

It does not directly generate reports. Report generation requests go to OpenClaw.

## Pages

### 1. Login / Register
Fields:
- Name
- Email
- Password

### 2. Organization Setup
Purpose:
Create first organization.

Fields:
- Organization name
- Organization slug

### 3. Main Dashboard
Cards:
- Total projects
- Total employees
- Connected repositories
- Reports generated
- Risk summary
- Most active project

### 4. Projects
Features:
- List projects
- Create project
- Edit project
- View project details
- Assign employees
- Connect repositories

### 5. Git Credentials
Features:
- Select provider: GitHub MVP
- Paste PAT
- Validate and connect
- Show status
- Reconnect
- Delete credential

Important:
- Never show PAT after saving.

### 6. Repository Sync
Features:
- Sync repositories
- View accessible repositories
- Select repositories to manage
- Assign repository to project
- Show private/public status
- Last synced time

### 7. Employee Management
Features:
- Add employee
- Edit employee
- Assign role
- Assign projects
- View employee details

### 8. Contributor Mapping
Features:
- View detected Git identities
- View mapped identities
- View unmapped identities
- Map identity to employee
- Remap identity
- Merge duplicates
- Ignore identity

UI Example:

```text
Detected Git Identity           Mapped Employee
------------------------------------------------
rahimdev / rahim@company.com    Rahim Ahmed
karimdev / karim@company.com    Karim Uddin
unknown@email.com               Unmapped [Map]
```

### 9. Generate Report
Fields:

## User Flow: Manager Setup

```text
Login
-> Create Organization
-> Add Git Credential
-> Sync Repositories
-> Select Repositories
-> Create Project
-> Assign Repository
-> Add Employees
-> Map Contributors
-> Generate Reports
```

## User Flow: Employee Report

```text
Login
-> Assigned Projects
-> Generate Report
-> Select Period
-> Request goes to OpenClaw
-> View Report
-> Share if allowed
```

## Dashboard to OpenClaw Contract

Dashboard sends structured report request:

```json
{
  "source": "dashboard",
  "organizationId": "org_123",
  "requesterId": "user_123",
  "projectId": "project_123",
  "repositoryId": "repo_123",
  "employeeIds": ["user_456"],
  "period": "last_7_days",
  "reportType": "employee",
  "customPrompt": null
}
```

## Design Principles

- Simple setup wizard
- Clear security messaging for PAT
- Make unmapped contributors obvious
- Make report generation simple
- Keep statistics easy to understand
- Avoid overwhelming employee dashboard
